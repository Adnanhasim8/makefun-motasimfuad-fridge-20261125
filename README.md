# Notes From a Passive-Aggressive Fridge

One funny passive-aggressive note a smart fridge leaves for its owner — a single dry, petty, specific line for its door screen. The fridge counted 14 door openings last night; the ice cream never moved. It noticed.

## How to run

```sh
python3 main.py
```

This writes the note to `/output/entry.txt` (UTF-8, one line, under 200 characters). No network is used at run time. Python 3.13 standard library only.
